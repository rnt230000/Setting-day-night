## Description
This project gives users the option to change the background setting using four buttons: Day, Night, Clear, and Cloudy. When the program is executed, a window opens displaying a panda sitting in an empty landscape with four buttons below it. Some buttons may appear blacked out and disabled, which indicates that the corresponding setting is already active. For example, if the Day button is blacked out, the daytime setting is currently active. What are the expectations for each button?

### Day Button:

If the current setting is nighttime, the black background will gradually fade to cyan as the moon descends and the sun rises behind the landscape.

### Night Button:

If the current setting is daytime, the cyan background will gradually fade to black as the moon rises and the sun descends behind the landscape.

### Cloudy Button:

This setting makes the sun and moon disappear, leaving only a gray background. However, the Day and Night buttons will still remain active and continue to affect the background color. If the setting is daytime, the cloudy background will appear light gray; if the setting is nighttime, the background will appear dark gray.

### Clear Button:

This setting removes the gray background, allowing users to see the sun and moon again.
